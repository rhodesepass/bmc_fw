连接帮助与操作说明 ＋

使用支持 Web Bluetooth 的 Chrome / Edge，并从 localhost 或 HTTPS 打开本页。Linux 上可能需要启用 chrome://flags/#enable-experimental-web-platform-features，重启浏览器后再连接。

每次只允许一个 BLE 客户端连接。若连接失败，请先断开手机或其他调试工具。日志“回放”读取设备侧已有缓存；“保存”导出当前页面收到的日志。

APP 终端通过 BMC 转发 UART 输入。D1s 处于复位或 FEL 状态时不会提供 Linux shell。“进入 FEL”控制启动路径，不会自动给空 NAND 写入固件。

C3 下载和救援操作会改变设备状态。网页只通过 BLE 请求切换模式，无法执行 xfel、加载 uopbridge 或调用 esptool；后续操作请使用电脑终端。
